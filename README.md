A [make.fun](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) entry: one program that writes a single one-line 1-star review, in the voice of a houseplant, about the human who owns it.

## The entry

> One star. He pruned me with the kitchen scissors — the ones he uses on raw chicken. I can taste the poultry in my wounds, and he calls it a haircut. Buy proper shears, you absolute goblin.

## Run

```sh
python3 main.py   # writes /output/entry.txt (190 characters, one line)
```

Python 3.13, standard library only. No network, no dependencies.
